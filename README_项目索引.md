## 文件名规则

- 章节文件统一使用：`第01章_类型_标题_版本.md`；
- `研究卡`、`初稿`、`扩写稿`、`修订稿`、`审校记录`、`精修说明`表示文件用途；
- `v0.x`表示过程稿，`v1.x`表示阶段性定稿或审校稿；
- 合稿文件统一以 `唐朝那些事儿_册名_版本.md` 命名；
- 过程稿全部保留，不覆盖、不删除。
