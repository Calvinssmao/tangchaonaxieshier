# 《唐朝那些事儿》项目索引

本项目已经改用 Git 管理版本。工作目录只保留每份文档的当前内容，文件名不再附加 `v0.1`、`v1.0`、`v2.0` 等版本号；旧稿通过提交记录和标签读取。

详细操作见：[Git版本管理说明](00_总纲与管理/Git版本管理说明.md)。

## 目录结构

```text
00_总纲与管理/                 总纲、写作规范、项目级计划与管理工具
01_第一册_大唐开国/
  00_写作包与进度/             写作包、进度表
  01_合稿/                     当前连续阅读合稿
  02_章节稿件/                 第1—11章当前正文
  03_研究卡/                   第1—11章当前研究卡
  04_审校修订/                 各章审读记录与全册审校材料
02_第二册_贞观君臣/            结构同上，第12—22章
03_第三册_武后的天下/          结构同上，第23—33章
03_学习辅助/                   时间表、制度表、对外关系表和复习提要
website/                       独立 Git 仓库，不纳入书稿仓库
```

第三册旧版“高宗与武后”结构已经从当前目录移除，保存在 `v1.0` 标签及其以前的 Git 历史中。

## 文件名规则

- 章节正文：`第01章_皇帝照见的最后盛世.md`；
- 研究卡：`第01章_研究卡_皇帝照见的最后盛世.md`；
- 单章审读：`第01章_审读记录.md`；
- 全册合稿：`唐朝那些事儿_第一册_大唐开国.md`；
- 进度表、写作包及管理文件使用固定名称；
- 文件发生修改时覆盖当前文件并提交 Git，不复制出带版本号的新文件。

## 日常维护

新增或重写章节时，直接修改固定路径中的正文、研究卡和审读记录，然后提交一次含义清楚的 Git 变更。全册合稿生成后放入 `01_合稿`，并同步更新对应进度表。

网站继续把 Markdown 目录作为内容来源。书稿文件改名后，需要在网站仓库中重新运行内容同步；网站当前未提交的改动没有纳入本次迁移。
