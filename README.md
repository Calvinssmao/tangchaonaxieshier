# 《唐朝那些事儿》

一部以学习唐史为目的的通俗历史长篇。全书计划八册八十八章，以“控制与失控”为总主线：唐朝怎样建立国家能力，怎样把力量交给不同的人，又怎样在一次次失控以后继续生存。

正文追求故事性、人物动机和作者判断，同时以正史为主要依据。制度、科技文化与对外关系通过真实事件进入叙事，不写成独立讲义。

## 写作与版本规则

- 章节正文、研究卡、审读记录和合稿均使用固定文件名，不增加 `v0.1`、`v1.0` 等版本后缀。
- 修改直接写回当前文件；旧版本通过 Git 提交记录和标签读取。
- 每章按“研究卡—连续故事初稿—单章审读”推进，相邻章节完成后进行分组统稿。
- 初稿从开始就包含故事性，不另设“故事化复写”步骤。
- 全册完成后制作包含正文全文的实体合稿，并复核史实、称谓、主题、制度线、人物伏笔及跨册连续性。
- 数字史料角标不进入正文；标题通常使用年号，不直接使用公元年份。
- 每次修改只暂存相关文件，检查差异后提交并推送。

第三册旧版“高宗与武后”结构保存在 `v1.0` 标签及更早的 Git 历史中。网站继续以 Markdown 书稿为内容来源，书稿路径变更后需在网站项目内重新执行内容同步。
