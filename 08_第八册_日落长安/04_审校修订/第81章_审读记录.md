# 第81章《沙陀骑兵进入中原》单章审读记录

## 完成情况

- 正文初稿及单章审读完成，14,087个非空白字符。章首承第80章唐军入长安的结果，回到中和二年召李克用的处境，沿代北前史、入援、沙苑与梁田陂、华州与渭南、获授河东、陈州解围、王满渡与封丘追击，顺写至中和四年六月黄巢死于狼虎谷。正文由20个碎小节合并成15个叙事小节，不用标题打断追击线。
- 李克用由唐廷旧敌变为援军，不抹去杀段文楚及父子据镇的前史；收复长安不归于一支骑兵，河中、易定、忠武等军及杨复光的行营协调均有位置。沙陀军以代北部众和蕃、汉兵构成，不写成单一种族的神奇骑兵。
- 节度使制度从晋阳接收仓库、安民榜文和军粮供给进入叙事，说明临时召兵如何变成授镇、养兵和后来不易收回的地方权力。陈州围城与黄巢残军瓦解也通过营垒、渡口、降将换旗、冤句断粮展开，而非以战名串联。

## 时间、史源与表达边界

- 对照《资治通鉴》卷二百五十三至二百五十六、《新唐书》卷二百一十八《沙陀传》及两《唐书》黄巢传，校正“李克用获河东任命—经榆次探父—八月入晋阳”的先后。上源驿在中和四年五月，狼虎谷之死在六月；正文先写赴宴邀请，再写死讯，末尾明确是以六月回望五月。
- 研究卡误将《旧唐书》卷一百七十九列为李克用传，实为萧遘等列传；已改用《新唐书》沙陀传与两《五代史》李克用记载，并补《新唐书》卷二百二十五下黄巢传。李克用“一目微眇”不扩写为一目全盲。
- “鸦军”、黄巢送赂与南山寺僧、李克用安民榜文、王满渡半渡受击和释放被掳男女有史事依据。军营和城内无名人物的细部反应只作处境推断，不给虚构者姓名和史实对白；兵额、斩获、陈州极端暴行数字不作现代意义的精确统计，黄巢死法分歧置于章末史料说明。
- 正文标题和小标题不用公元年份，无数字史料角标及面向读者的讲课句；第80—81章没有35个非空白字符以上的相同整段。字数和格式检查通过。

## 章际接口

- 第80章从大齐占领与失去长安的视角写结果；本章从唐廷召李克用、沙陀军组织与联军作战写原因，长安入城只保留必要战斗与胜军暴掠，不重演大齐建政和清洗。
- 第82章应在首段明示回拨中和二年，从朱温投唐起笔，讲清赐名、汴州与宣武军。第81章只写他在河南救援、接收降将及邀请李克用赴宴；上源驿内的冲突与两人决裂尚未展开。
