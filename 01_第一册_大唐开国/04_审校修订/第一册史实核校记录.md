# 第一册 v1.4 第二轮史实核校记录

## 核校范围

本轮优先检查突厥关系、太原起兵、长安建唐、虎牢关、武德末年边患和玄武门等最容易被后世叙事压平的节点。核校以《资治通鉴》相关卷次为主，正文仍保留“数量表达量级、心理属于推断”的写法。

## 已核对节点

| 节点 | 核校结果 | 处理 |
|---|---|---|
| 武德元年前后李渊与突厥 | 《资治通鉴》卷184记突厥送马千匹互市，并许以出兵相送；李渊担心胡骑入境，要求援助有边界 | 正文保留为“借力与债务”，不写成无条件同盟 |
| 刘武周起兵与汾阳宫 | 卷183记二月杀王仁恭、据马邑，三月袭破楼烦并进取汾阳宫，随后获得突厥支持 | 已将第三章开头“二月拿下汾阳宫”改为“三月进取汾阳宫”，并补出二月起兵过程 |
| 西河战事 | 卷184记李建成、李世民攻西河，往返凡九日 | 保留“九日”，并注明数字可经史家修饰，只说明行动迅速 |
| 王世充与突厥 | 卷188记突厥献马千匹、求婚并互市；同卷又记处罗可汗遣二千骑助唐 | 正文明确突厥同时向不同中原力量下注，不写成固定阵营 |
| 渭水交涉 | 卷191记颉利、突利进寇，李世民轻骑出面、唐军继至、便桥盟誓后退兵；又记李世民解释不战原因 | 正文保留共同骨架，降低精确对白和人数的确定性 |
| 玄武门行动 | 卷191记李建成、李元吉入临湖殿、玄武门交战及东宫兵溃 | 正文区分“事件结果”与政变前指控，不把后世政治指控直接当作事实 |
| 可汗称谓 | 始毕、处罗、颉利、突利在不同阶段执政或参与行动 | 已统一首次出现时加“可汗”，后文按语境简称，避免把不同权力阶段混为一谈 |
