# 第四章《从太原到长安》总纲重写审读记录 v2.0

## 审读结论

通过，可作为第一册新版合稿候选章。

本章已经形成稳定的南下时间线：贾胡堡因雨与缺粮发生回师争论，霍邑通过诱敌和苦战打开道路，战后处置与授勋推动扩军，平阳公主在关中完成另一条组织线，突厥战马于龙门抵达，主力渡河取得永丰仓，最终合围并攻入长安。制度内容均由军队当时遇到的问题引出，没有另作百科插页。

## 本次直接修订

| 检查项 | 发现的问题 | 已作处理 |
|---|---|---|
| 段落节奏 | 多处十余字的承接句独立成段，容易形成连续顿挫 | 合并雨势、回师、人物出场、游说、突厥援助等处短段，保留战役转折所需停顿 |
| 称谓口径 | 唐朝尚未建立，霍邑等处数次提前使用“唐军” | 改为“李渊军”“李氏军”或“新军”；唐朝建立后的追叙仍保留唐军称谓 |
| 战场语言 | “后却”等用语略显生硬 | 改为更直接的“后退”，降低文言讲义感 |
| 兵力数字 | 城外“二十余万”直接陈述，容易被读者当作精确可战兵力 | 明确这是开国材料口径，包含大量新附队伍，不能与统一编制的战兵等同 |
| 章节平衡 | 原第十节同时承担围城、破城和接管，明显长于其他部分 | 在正式破城处拆出“城门之后”，使军事高潮与政治接管分别完成 |
| 人物与制度 | 霍邑、平阳公主已有完整行动，但容易被结论句截断 | 将柴绍侦察、马三宝游说、官位授予等判断并回事件段落 |

## 重点内容复核

- 宋老生被写成需要在守城与主动决战之间选择的隋将，没有因失败而被简单判定为蠢人。
- 李建成与李世民共同完成贾胡堡劝阻和霍邑作战，没有让李建成隐身，也没有把李世民的成功写成预知结局。
- 平阳公主部分包含散财、招募、马三宝游说、联合多股武装、军纪、占地、会师和各置幕府；军礼葬仪作为可靠趣事简短回照其历史评价。
- 奴婢按功授勋写清了产生原因、实际处理和制度边界，没有夸大为废除良贱等级。
- 永丰仓同时写出隋代仓储来源、清点分粮的执行过程、军纪效果和被新政权接管后的意义。
- 突厥援助继续使用“约五百人、二千匹马”的史料坐标，并注明其他材料口径有别和双方目标不同。

## 合稿阶段再处理

- 与第三章统一突厥战马、援兵数量和刘文静出使的表述，第三章讲交易形成，本章只保留援助兑现。
- 与第五章统一杨侑年龄、李渊拜见及拥立程序；第四章止于军事占领与接管，第五章负责合法性转换。
- 全册新版章节完成后，再检查本章回看是否与第九章关于国家日常运转的制度说明重复。
