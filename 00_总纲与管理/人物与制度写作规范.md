# 《唐朝那些事儿》人物与制度写作规范

> 版本：v1.0　适用于后续章节重写与第三册创作

## 一、人物写法：先让人物站起来

人物第一次出现时，尽量完成四件事：

1. **基本身份**：姓名、出身、年龄或时代位置、当时担任什么职务；
2. **与当前事件的关系**：他为什么会出现在这里，手里有什么资源，害怕什么；
3. **历史趣事**：选择一则与性格或命运有关的真实轶事，标明是正史、杂史还是后世传说；
4. **作者判断**：用一句带幽默感的评价让读者记住他，但不把人物简化成标签。

### 人物介绍的推荐顺序

> 出场场景 → 生平背景 → 趣事或反差 → 当前目标 → 行动与后果 → 后来命运

### 幽默使用原则

- 幽默用来揭示性格、制度荒诞或权力处境，不用来取消人物责任；
- 可以调侃人物的习惯、口才、仪式和自我辩护，但不拿现代道德优越感替代分析；
- 趣事必须有史料等级：明确记载、后世整理、民间传说要区分；
- 不把未经证实的逸闻写成确定事实，不用“据说”掩盖出处不明；
- 幽默之后要回到人物的选择和代价，不能让笑点成为结论。

### 人物评价的四个维度

每个主要人物至少从以下四项中写出三项：

- 动机：他想得到什么、害怕什么；
- 能力：他擅长什么，短板是什么；
- 处境：制度、家族、战争和信息如何限制他；
- 结果与责任：他的选择造成什么后果，哪些不能甩给时代。

## 二、制度写法：让制度从事件里长出来

介绍制度时不得只给名词解释，应按以下六步推进：

### 1. 先写制度要解决的麻烦

从一次真实事件、一道诏令、一场争论或一个家庭的困境开始。先让读者看到“没有这套制度会出什么问题”。

### 2. 说明制度怎样产生

交代它继承了什么旧制度、因哪场危机或哪位人物而调整、谁支持、谁反对。区分正式创设、临时措施和后世总结，避免把成熟形态倒推到最初。

### 3. 讲清具体内容

用白话说明：谁有权提出、谁审核、谁执行、适用范围是什么、例外是什么、文书和期限如何规定。只解释当前故事需要的部分，不做百科全书式铺陈。

### 4. 写制度如何执行

把制度落到官员、军队、农户、商人、妇女、奴婢或边疆部落身上，说明谁填写、谁运输、谁出钱、谁承担时间和风险。制度必须有动作、地点和成本。

### 5. 用真实事件点评好坏

至少写一个制度成功解决问题的案例，再写一个执行走样、被规避或制造新问题的案例。评价不只问“先进不先进”，还要问：

- 是否降低了不确定性；
- 是否让责任更清楚；
- 成本由谁承担；
- 是否给弱者留下申诉空间；
- 是否过度依赖某个皇帝或官员。

### 6. 追踪后续发展与崩坏

写制度如何扩张、变形、被权力集团利用、因财政或战争压力失效，或被下一代重新修补。制度的结局不能只写“后来废除”，要说明它为什么失去原来的功能。

## 三、人物与制度必须互相连接

- 人物不是制度的插图：写他如何利用、误解、抵抗或修补制度；
- 制度不是人物的背景：写它如何奖励、限制、筛选和改变人物；
- 每章至少安排一处“人物选择改变制度结果”，或“制度约束人物选择”的场景；
- 评价人物时，不把制度责任全部推给个人；评价制度时，也不替个人免除责任。

## 四、章节节奏建议

一章约8,000—10,000字时，可参考：

- 55%—65%：场景、行动、对话推测、事件后果；
- 20%—30%：人物动机、制度解释和作者评论；
- 10%—15%：史料说明、争议边界和章末回望。

每个抽象判断后，尽量紧接一个具体例子；每个制度段落后，尽量回到一个正在做事的人。

## 五、作者口吻

可以幽默，可以和读者对话，也可以提出带刺的评价，但不要连续用同一种句式。少用空泛的“这说明了……”作为段落结尾，多用人物下一步行动、制度留下的账单或一个普通人的具体感受收束。

正文可以保留少量有叙事感的小标题，但避免“第一步、第二步”式的程序化拆解，尤其在连续案情中应通过段落转场自然推进。研究卡、进度表和审校记录可以使用说明性小标题，便于检索，但不得直接照搬进正文。

### 纪年表达

- 正文优先使用历史人物当时所处的年号，不把公元年份当作主要叙事语言。
- 章名和小标题原则上不出现公元年份；需要时间提示时使用年号，或改用事件、地点和人物处境命名。
- 新阶段首次定位、跨政权对照、跨度过大或年号容易造成理解困难时，可以在正文中补充一次公元年份，并说明其作用；同一事件附近不反复使用“年号＋公元”双重标注。
- 研究卡、年表、进度表、资料索引和史料说明可以继续使用公元纪年，以便检索和校勘。

## 六、最终自检问题

### 写人物前问

1. 读者知道他从哪里来吗？
2. 有没有一件可靠趣事让他不再只是姓名？
3. 他的目标、能力和恐惧是否不同？
4. 评价是否回到了行动和责任？

### 写制度前问

1. 它因什么麻烦产生？
2. 谁设计、谁支持、谁反对？
3. 具体如何执行，成本由谁承担？
4. 哪个真实事件证明它有效或失效？
5. 后来怎样发展、变形或崩坏？

### 交稿前问

1. 章名和小标题是否误用了公元年份？
2. 正文能否优先以年号推进，又不让普通读者失去时间坐标？
3. 补充的公元年份是否确有跨时段、跨政权或首次定位的必要？
