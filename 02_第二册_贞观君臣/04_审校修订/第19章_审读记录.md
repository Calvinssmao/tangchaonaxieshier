# 第十九章《东宫里的失败者》初稿审校记录

> 版本：v0.1　日期：2026-09-01

## 一、结论

初稿可进入精修。章节把李承乾、李泰和李治放在储位制度、皇帝偏爱、东宫信息网络和军功集团的交叉点上，没有把承乾简单写成“突然堕落”，也没有把李泰写成从一开始就策划夺嫡的单一反派。

正文约8,006个汉字，基础检查未发现TODO、占位符或中文引号不配对问题。

## 二、史实核对

| 项目 | 结果 | 处理 |
|---|---|---|
| 太宗诸子与储位关系 | 李承乾、李泰、李治均为长孙皇后所生，承乾为太子，泰受宠，治后来被立 | 正文按嫡长、宠爱与第三方案展开，未混淆母系关系 |
| 李承乾足疾与外间议论 | 《资治通鉴》记太宗听闻太子有足疾、魏王颖悟而产生异议 | 正文说明身体问题被政治化，没有断言足疾必然导致不能执政 |
| 东宫辅弼 | 魏征、孔颖达、于志宁等曾参与太子教育或东宫政务 | 正文用“师傅—观察者”双重视角，未虚构完整日常对话 |
| 李泰声望 | 史书记其才学与受宠，后世多据此解释储位竞争 | 正文把才华与政治后果区分，避免把有才等同有罪 |
| 侯君集等人卷入 | 正史记承乾谋划与侯君集、杜荷等有关，具体过程有详略差异 | 正文使用“卷入”“形成联系”等限定，不补写秘密会议 |
| 废承乾、黜李泰、立李治 | 《资治通鉴》卷197记承乾获罪后，太宗一度欲立李泰，长孙无忌等固请立晋王治 | 正文呈现第三方案及其辅政代价，没有写成李治偶然捡漏 |
| 处理结果 | 承乾被废并徙居，李泰降封，李治为太子 | 正文强调两位失败者都保住性命但失去政治未来 |

## 三、精修时注意

1. 李承乾亲近突厥服饰、称心等材料带有道德化叙述和后世编纂色彩，精修时继续使用史料限定，不把它们当作完整心理证据。
2. 太宗的“偏爱”要写成父爱与皇帝责任的冲突，不暗示他从一开始就有明确废太子计划。
3. 李泰的文学活动、宾客网络与政治威胁之间要保持因果距离，避免“有文士来往=已经谋反”的跳跃。
4. 侯君集的军功身份是制度风险的一部分，但不要把唐朝军功集团写成统一行动的现代政党。
5. 李治被立的原因涉及兄弟安全、名分、辅政和皇帝心理，保留多因素解释，为后续高宗政治埋线。
6. 废立后的迁居、降封和生活影响属于制度推演，不能增加未经互证的地点细节和个人对话。

## 四、节奏建议

本章从东宫日常切入，逐步扩大到兄弟竞争、军功集团和废立决策，结构完整。精修时可略压缩“传言—猜疑—监视”的同义循环，把篇幅留给两个转折：一是太宗公开宠爱李泰造成的制度裂缝，二是废承乾后太宗发现李泰也不能直接继承。结尾保留“继承问题从来不只是家事”，与第二十章外交婚姻线形成对照。
