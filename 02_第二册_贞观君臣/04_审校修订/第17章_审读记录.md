# 第十七章《天可汗》总编辑审校记录

> 日期：2026-09-08　对象：新版重写稿

## 一、审校结论

本章总编辑初审通过，可同步第二册连续合稿。

正文共12,580非空白字符，已经从旧稿的称号与制度说明，重构为一场持续十三年的边疆治理实验：贞观四年接受天可汗称号，近十万降众引发安置争论，府州与宿卫开始执行；突利、颉利先后在新秩序中走完人生；贞观十三年结社率夜袭九成宫，太宗改变政策；阿史那思摩被册立为可汗，最终仍在贞观十七年失去部众。

故事、制度与评价的次序基本正确。每项制度先由具体难题产生，再说明内容和执行，最后由九成宫遇袭、思摩部众南返检验其得失，没有停留在“唐朝实行羁縻政策”的结论层。

## 二、关键史实核对

| 核对项 | 审校结果 | 正文处理 |
|---|---|---|
| 天可汗称号 | 《资治通鉴》记贞观四年三月诸部君长请太宗为天可汗；《唐会要》记玺书使用“皇帝天可汗” | 写成皇帝与可汗身份叠加，不扩大为全部草原、西域共同授权 |
| 章节开篇时间 | 颉利四月在顺天楼受见，天可汗请求发生于此前三月 | 开篇明确将日历回拨一个月，避免与第十六章结尾形成无提示的时间倒退 |
| 降众规模 | 史籍概称近十万；思结俟斤另有率众四万来降记录 | 明确人口并非纯战士，不把不同数字机械相加 |
| 安置朝议 | 颜师古、李百药、窦静、魏征、温彦博各有方案 | 不压缩成魏、温二人善恶辩论，并分别解释安全、生计与分部制衡逻辑 |
| “河南”含义 | 材料中迁兖、豫与置河南、朔方并存；北疆语境中的河南不可简单等同今日河南省 | 正文按兖豫州县与河套以南、朔方一带分写，消除旧稿地理歧义 |
| 府州设置 | 突利旧地置顺、祐、化、长四州都督府，颉利旧地分六州，以定襄、云中两都督府统摄 | 解释为依托部落首领的间接治理，不类比现代省区，也不写成成熟定型制度 |
| 酋长授官与长安人口 | 史籍记五品以上首领百余人，数千家或近万家入居长安 | 以概数说明规模，未把全部居民写成宿卫 |
| 《王会图》 | 贞观四年远方来朝者众，颜师古请图写其服饰 | 作为文化与国家认知场景，不把图像秩序等同现实控制 |
| 突利结局 | 任右卫大将军、北平郡王、顺州都督，贞观五年病卒并州，年二十九 | 不虚构死因，借双重身份展示部落首领兼唐官的张力 |
| 颉利结局 | 在长安悲歌，拒任虢州刺史，改授右卫大将军；贞观八年死后依本俗火葬 | 不补写歌词与内心结论；以旧臣殉死表现旧忠诚没有随官号消失 |
| 九成宫事件 | 结社率联络四十余人，拥贺逻鹘夜袭行宫，突破营幕后败亡 | 写清计划、偶发变化、行动和处置；明确不是十万降众集体反叛 |
| 太宗改策 | 事后承认不用魏征之言几至狼狈，命内置部众北渡并册立思摩 | 解释为从近地吸纳转向边疆代理，并非完全照搬魏征原方案 |
| 思摩结局 | 受册后畏薛延陀，部众逐步北渡；至贞观十七年离散南返 | 写到制度失败结果，不把册封和北渡压缩为同一天完成 |

## 三、人物与动机审校

### 唐太宗

正文同时保留其威望、试验精神和个人名声需要。接受称号既是把军事胜利转成秩序，也是对渭水压力的政治补偿；采用温彦博之策表现其容纳不同人群的雄心，九成宫之后承认后悔又说明他会被近身安全改变判断。没有写成从头到尾知道答案的明君。

### 魏征与温彦博

魏征对人口、组织和王畿距离的风险判断得到充分呈现，其“人面兽心”式族群本质论被明确区分。温彦博既有人道关怀，也想以降众守边、酋长宿卫降低成本；正文说明他高估了短期教化与个人恩德，却没有用后来事件否定其对牧业生计的理解。

### 突利、颉利、结社率与思摩

四个人承担不同制度结果。突利是同时面对本部和唐法的中介；颉利是得到官职却失去实际身份的俘虏；结社率是进入宿卫后利用内部信息反抗的人；思摩则是中央最信任、地方未必最愿追随的代理首领。这组人物使“首领授官”不再是名词介绍。

### 薛延陀

正文保留薛延陀作为第三方，解释思摩不敢出塞、太宗玺书划界和部众最终南返。唐朝先借夷男牵制颉利，后来又以思摩牵制薛延陀，符合全书“联盟制造新强者”的突厥关系线。

## 四、制度、文化与对外关系审校

1. 册封和鼓纛由“谁有资格召集部众”带出，说明低成本与代理人威望不足的风险。
2. 都督府由近十万降众安置带出，交代产生原因、依托首领的执行方式、与中原州县的区别及后续变形。
3. 宿卫由首领入长安带出，既写礼遇、俸禄和个人联系，也写近距离安全风险。
4. 玺书、使者、翻译和军事担保由唐廷调停思摩与薛延陀带出，技术与信息没有写成独立成就清单。
5. 《王会图》、颉利本俗火葬和长安新居民承担文化线，均服务于人物与制度，不另作“民族融合”颂歌。
6. 对外关系集中于东突厥余部与薛延陀，没有沿用旧稿横扫西突厥、高昌、伊吾等方向的名单式铺陈。

## 五、总纲与叙事检查

- 全章按贞观四年、五年、八年、十三年、十五年前后、十七年推进；开篇唯一一次回拨已明示；
- 第十六章写战争胜负，本章从称号和降众安置开始，没有重讲定襄、阴山与唐俭；
- 开篇“威风名片也是账单”与结尾“鼓纛由长安赐下，是否跟随由草原上的人决定”前后呼应；
- 九成宫事件是全章动作高潮，前面的宿卫两面性和突利家族线均为其服务；
- 解释集中在事件之后，没有在关键情节尚未说清时连续作抽象评价；
- 正文没有公元年份，没有“上一章”“下一章”“文学化还原”和步骤式提示；
- 中文双引号数量相等，未发现TODO、占位符和残留版本号；
- 正文没有虚构普通降众姓名、颉利歌词、结社率誓词或思摩与薛延陀的私下对白。

## 六、仍需在第16—18章统稿时检查

1. 第十六章结尾已经提出降众安置难题，本章开头只保留最短承接，不再增加战争回顾。
2. 第十六章四月献俘与本章三月称号存在一个月交叉，目前已明示回拨；三章统稿时再检查是否需要进一步压缩第十六章长安场面。
3. 本章多次出现“称号不能代替控制”的判断，当前均有不同事件支撑；与第十八章统稿时仍应检查是否有同义重复。
4. 第十八章涉及太宗经营历史形象时，可以引用其承认错误的政治风格，但不重复魏征与温彦博全部安边争论。
