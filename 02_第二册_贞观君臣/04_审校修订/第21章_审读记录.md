# 第二十一章《皇帝最后一次远征》初稿审校记录

> 版本：v0.1　日期：2026-09-01

## 一、结论

初稿可进入精修。章节将贞观十九年征高句丽写成“道义名分、历史记忆、帝国完整想象与后勤边界”共同作用的决策，没有把战争简化成太宗好大喜功或纯粹吊伐。海陆并进、攻城器械、安市城坚守、粮储不足与班师形成清晰的行动线，普通家庭和民夫承担的动员成本也已纳入叙事。

正文约8,005个汉字，基础检查未发现TODO、占位符或中文引号不配对问题。

## 二、史实核对

| 项目 | 结果 | 处理 |
|---|---|---|
| 出兵名义 | 高句丽盖苏文弑高建武、专权，太宗以弑君虐下和新罗问题为出兵理由 | 正文区分唐朝政治名义与高句丽内部国家利益，未写成人人欢迎唐军 |
| 海陆并进 | 张亮水军由莱州趋平壤，李勣、李道宗等由辽东推进 | 正文强调海运、陆路、船只、民夫与多路协同的后勤难度 |
| 辽东诸城战事 | 史书记盖牟城、辽东城等相继被攻克，并设州置守 | 正文将局部胜利与征服高句丽整体区分，不夸大为大势已定 |
| 太宗亲临前线 | 史书记负土填堑、为李思摩吮血、撤桥等行为 | 正文兼写将士鼓舞与皇帝权力表演，不把典范化细节当作全军感受 |
| 安市城与援军 | 高句丽十五万援军在安市附近败退，安市城继续坚守 | 正文将山城、土山、器械和时间写成结构性阻力 |
| 粮储与班师 | 史书记辽东仓储不足、士卒寒冻，太宗下令撤军 | 正文解释撤军是后勤止损，不使用“只差一步”替代原因 |
| 战后抚恤 | 太宗祭祀战亡者、赎回部分俘虏，后仍有再伐计划 | 正文保留同情与战争责任并存的矛盾 |
| “最后一次远征”标题 | 太宗贞观二十二年仍有再伐高句丽意图，未及出兵即崩 | 正文限定为最后一次亲征和晚年未竟目标，不称最后一次战争意图 |

## 三、精修时注意

1. 盖苏文弑君是唐朝的出兵名义，不能直接当作高句丽全社会的道德共识。
2. “十五万援军”是史书概数，精修时保持数量限定，不扩展为精确军籍。
3. 安市城主姓名、城址和攻城细节在史料间有异文，正文继续使用稳妥称呼。
4. 抛车、撞车、火攻、土山等技术应服务于“时间与后勤”的主线，不写成器械清单。
5. 太宗亲为李思摩吮血等细节具有史家典范化色彩，保留其象征意义但避免心理断言。
6. 普通家庭、民夫和阵亡者名册属于制度影响的解释性推演，不增加具体农户姓名和精确损失数字。

## 四、节奏建议

本章前半由“天下大定，唯辽东未宾”引出历史记忆与出兵名义，中段以海陆并进和安市城攻防制造行动张力，后半转入粮储、班师、家庭成本和皇帝遗憾，结构完整。精修时可略压缩技术器械的重复说明，把篇幅留给尉迟敬德反对亲征、太宗亲临前线和决定班师三个节点。

结尾“国家能力的边界”应保留，并与第二十二章“英雄迟暮”衔接：远征后的身体损耗、未竟功业和继承安排将成为最后一章的三条线。
