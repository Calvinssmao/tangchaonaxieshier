# 第二十二章《英雄迟暮》初稿审校记录

> 版本：v0.1　日期：2026-09-01

## 一、结论

初稿可进入精修。正文约8,100个汉字（含标题、章末回望），无TODO、占位符，中文引号成对。叙事完成了从辽东战后恢复到太宗病逝、高宗即位的闭环，且把制度、财政、对外关系和人物动机放在同一条“个人功业如何转成可继承秩序”的主线上。

## 二、史实核对

| 项目 | 结果 | 处理 |
|---|---|---|
| 太宗病中安排 | 《新唐书》《旧唐书》均记贞观二十三年诏皇太子在金液门听政，后幸翠微宫 | 正文写为病中程序化交接，不扩写具体奏疏内容 |
| 太宗死亡 | 五月己巳崩于翠微宫含风殿，六月甲戌李治即位于灵柩前，时年二十二 | 正文日期与地点准确，礼仪场景保留文学化但不冒充实录 |
| 禁军护送 | 史载以羽檄发六府甲士四千，护卫皇太子入京 | 正文只写禁军护送，不把四千人写成现场可核的精确部署 |
| 高宗初政 | 即位后大赦，供军劳役尤甚地区给复；贞观年号沿用至次年改永徽 | 正文将赦令与战争恢复、降低交接风险联系起来 |
| 高句丽再伐意图 | 太宗死前仍有再伐计划，未及实施 | 标题和正文均限定“最后一次亲征”，不说最后一次战争意图 |
| 丹药与死因 | 正史记病情，后世常有服丹药致病说法，医学结论不一 | 正文明确“后世推测”，不写成确定死因 |
| 李治与元老 | 李治为太宗第九子，长孙无忌等在继承中有重要位置 | 正文不把后来的永徽政治倒灌为贞观末年既定阴谋 |

## 三、逻辑与主题检查

1. **继承线**：第19章东宫危机在本章回收，李治的“安全继承人”位置成为制度问题，而非性格评语。
2. **战争线**：承接第21章高句丽撤军，将粮运、复业、再伐意图和身体损耗连成一线。
3. **突厥与对外线**：以突厥、铁勒、吐蕃和高句丽并列，说明“天可汗”声望不能替代道路、粮食和地方治理。
4. **制度线**：金液门听政、三省文书、赦令、谥号和史馆构成权力交接的可见技术。
5. **作者声音**：有评价和动机推断，但使用“可能”“未必”“我特意说”等提示，未将心理推想伪装成史实。

## 四、精修建议

1. “辽东战后给复”可在定稿时补一处诏令出处，避免把不同年份的复业措施混为单一诏书。
2. “太宗晚年身体状况并不好”属于综合判断，可保留，但避免进一步断言具体病因。
3. 长孙无忌、李勣、褚遂良的角色需继续保持差异，不能在精修中合并成无条件一致的“元老集团”。
4. 昭陵工程段落是制度和社会线的解释性扩展，不添加具体役夫人数或工程期限。
5. 结尾已为第三册留下问题，精修时不要把高宗早期或武后故事提前展开。
